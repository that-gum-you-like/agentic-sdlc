## Things said in these recordings that are worth the watch

> "The specs are the product. Getting the code to work after you have really good specs is so much more trivial."

> "This is secretly an AI alignment class — alignment is really about being clear about what you want."

> "Don't argue with the agents — it poisons the context."

> "A new error is progress. Every time there's a new error, you have made progress."

> "Code is no longer a moat. We just invented aquatic warfare."

> "Software is a fungus and it's a fluid. Code is not a static thing."

> "You have to sleep and eat every single day. Just because now you can do infinite code doesn't mean you don't have to sleep."

## Cautionary tales

Real things that went wrong in class, so you can avoid them.

**The database deletion.** A student gave an agent a broad instruction to "optimize" a database.
The agent read that as: delete data already materialised elsewhere. Production data, gone.
*Be specific about what an agent may and may not touch — "optimize" means nothing on its own.*

**Kernel panic from too many agents.** A student ran too many agents at once and crashed their
machine. *Start with two or three, not ten. Move heavy workloads to a VM.*

**A 43% research fabrication rate.** An agent hallucinated nearly half its citations.
*Always verify research output — use a skeptic agent or a citation checker before trusting claims.*
