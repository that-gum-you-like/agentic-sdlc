# Requirement ID Prefixes

One ledger per project. Claim a prefix here before using it in a change's specs or tasks, so two
changes never mint colliding requirement ids. Cite as `<PREFIX>-REQ-nnn`; when citing a
requirement owned by another change, name that change beside it.

|---|---|---|---|
